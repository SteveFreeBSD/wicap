- Recommended action: exclude /admin from unauthenticated navigation tests or set WICAP_INTERNAL_SECRET for authenticated admin tests.

2) Live system logs require auth (Medium)
- Cause: same internal secret requirement as /admin.
- Impact: log panel requests rejected without secret.
- Recommended action: provide WICAP_INTERNAL_SECRET in soak environment or add read-only public status endpoint for health.

3) Laptop viewport CSS overflow (Low, XFAIL)
- Cause: layout overflow at 1280x720.
- Impact: minor UI overflow, already marked XFAIL.
- Recommended action: address in UI polish backlog.
